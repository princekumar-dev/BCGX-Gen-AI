# Task 1 — 10-K Financial Data Analysis (Microsoft · Tesla · Apple)

**BCG X GenAI Job Simulation · Task 1 of the AI-powered financial chatbot project**

**Objective.** Extract five key financial metrics — *Total Revenue, Net Income, Total Assets, Total Liabilities, and Cash Flow from Operating Activities* — for **fiscal years 2023, 2025 and 2025** from each company's **Form 10-K** on SEC EDGAR, then use **pandas** in a Jupyter notebook to analyze year-over-year trends and surface insights that would inform a production-grade AI financial chatbot.

## Methodology

1. **Filing selection.** Latest Form 10-K per company on SEC EDGAR (plus prior-year 10-Ks where the third balance-sheet year was needed):

   | Company | Primary filing | Accession |
   |---|---|---|
   | Apple | [FY2025 10-K](https://www.sec.gov/ix?doc=/Archives/edgar/data/0000320193/000032019325000079/aapl-20250927.htm) | 0000320193-25-000079 |
   | Tesla | [FY2025 10-K](https://www.sec.gov/Archives/edgar/data/1318605/000162828026003952/) + [10-K/A](https://www.sec.gov/ix?doc=/Archives/edgar/data/0001318605/000110465926053166/tm2611837d1_10ka.htm) (Part III only) | 0001628280-26-003952 |
   | Microsoft | [FY2026 10-K](https://www.sec.gov/ix?doc=/Archives/edgar/data/0000789019/000119312526323660/msft-20260630.htm) (FY24–25 comparatives) | 0001193125-26-323660 |

2. **Extraction** of the five metrics from the Consolidated Statements of Operations, Balance Sheets, and Cash Flows (inline-XBRL us-gaap tags underlying each 10-K).
3. **Independent verification** — all **45 data points** were re-checked line-by-line against the rendered statement tables in the filings (`scripts/verify_filings.py`). No restatements or reclassifications were found.
4. **Compilation** to Excel/CSV with full provenance, then **pandas analysis**: YoY growth (`groupby().pct_change()`), margins, ROA, leverage, cash conversion, 2-year CAGR, rankings, and charts.

*Fiscal calendars differ:* Microsoft FY ends Jun 30 · Tesla = calendar year · Apple FY ends late September — "FY2025" spans different 12-month windows.

## Key Findings

- **Microsoft — hyper-growth at scale.** Revenue +15.7% then +14.9% (2-yr CAGR ≈ 15.3%); net income +21.8% then +15.5% (CAGR ≈ 18.6%); net margin expanded 34.2% → **36.1%**. Assets ballooned **+50%** ($412B → $619B) on the AI datacenter build-out — yet leverage *fell* (liabilities/assets 49.9% → 44.5%). FY2025 OCF of $136.2B (48% of revenue) is the strongest cash engine of the three.
- **Apple — return to growth, record profit, softer cash flow.** Revenue re-accelerated (+2.0% → **+6.4%**) to $416.2B; FY2025 net income hit a record **$112.0B** (+19.5%, margin 26.9%). But **operating cash flow fell 5.7%** to $111.5B — a quality-of-earnings flag. The balance sheet deleveraged (liabilities $308.0B → $285.5B) yet stays the most leveraged (~80% liabilities/assets — the buyback-funded capital structure).
- **Tesla — profitability collapse with cash-flow resilience.** Revenue flat then declining (−2.9% to $94.8B); net income fell **−52.7% then −46.5%** ($15.0B → $3.8B; CAGR ≈ −49.7%), margin 15.5% → **4.0%**, ROA 14.1% → 2.7%. Yet **operating cash flow held steady at ~$14–15B** (3.9× net income in FY2025) — heavy D&A and working-capital efficiency. Assets still grew 29%.
- **Cross-company.** Three distinct stories: Microsoft = growth engine; Apple = mature compounder re-accelerating; Tesla = margin reset. Cash ≠ profit: OCF/net income ranges from Apple 1.0× to Tesla 3.9× — a chatbot answering "how profitable is X?" from net income alone would mislead.

## Relevance to the AI Financial Chatbot

- **Provenance-backed answers** — every figure carries its accession number and filing URL, enabling citations ("per Tesla's FY2025 10-K, filed 2026-01-29…").
- **Fiscal-calendar normalization** must be explicit, or cross-company "2025" comparisons are subtly wrong.
- **Rates over levels** — YoY growth, margins, ROA and leverage (all reproduced deterministically in the notebook) answer comparative questions better than raw dollars.
- **Definitional nuance** — *net income attributable to parent* vs consolidated (Tesla: $3,794M vs $3,855M FY2025, noncontrolling interests); GAAP profit vs operating cash flow divergence.
- **Restatement awareness** — compare filing vintages; none existed for these line items (itself a reportable finding).

## How to Run

**Browser (no install):** upload `financial_analysis.ipynb + financial_data.xlsx` to [jupyter.org/try-jupyter](https://jupyter.org/try-jupyter/) (or Google Colab) → **Kernel → Restart Kernel and Run All Cells**. If `openpyxl` is missing, run `%pip install openpyxl` first.

**Locally:**
```bash
pip install notebook pandas openpyxl matplotlib
cd task-1-financial-analysis
jupyter notebook        # open financial_analysis.ipynb → Run All
```

**Rebuild the dataset from source:**
```bash
python scripts/fetch_sec_data.py    # extract from SEC EDGAR
python scripts/verify_filings.py    # verify against filing statements
python scripts/build_excel.py       # compile financial_data.xlsx / .csv
```
